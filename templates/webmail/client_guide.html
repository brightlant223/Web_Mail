Brightlant Webmail — Basic User Guidelines

Super simple 4-step user guide for sending, receiving, and configuring Brightlant Corporate Webmail.

Download PDF Guide
1
1. Login & Access (लॉगिन करें)

Browser me http://127.0.0.1:5000 open karein. Apna email {{ current_user.email }} aur password daal kar Sign In dabayein.

2
2. Send Mail (ईमेल भेजें)

Compose New Mail par click karein. Recipient Email, Subject aur Message likhein. AI Copilot se auto text bhi generate kar sakte hain!

3
3. Receive Mail (ईमेल प्राप्त करें)

Inbox page par saare incoming mails dikhenge. Naya mail aate hi Sound Alert (Chime) aur screen toast notification aayega!

4
4. Test Mail (टेस्ट ईमेल)

Inbox me top bar par 📥 Receive Mail Test button dabayein. Kisi bhi external sender se test mail receive kar ke dekhein.

Step-by-Step Email Setup Guides for Mobile & Desktop Apps

Step 1: Open Microsoft Outlook -> Click File -> Select Add Account.
Step 2: Enter your email ({{ current_user.email }}) -> Select Manual setup or additional server types -> Choose POP or IMAP.
Step 3: Incoming mail server: {{ config.imap_host }} (Port 993, SSL/TLS).
Step 4: Outgoing mail server (SMTP): {{ config.smtp_host }} (Port 587, STARTTLS).
Step 5: Type your account password and click Connect. Setup complete!
